# rust-wavetable

A wavetable synthesizer written in Rust, with two interfaces:

- **Terminal** — keyboard-driven, plays audio natively via the system output device
- **Browser (WASM)** — interactive GUI with piano, oscilloscope, frequency control, and ADSR envelope editor

## Waveforms

| # | Shape | Harmonics / method |
| --- | ------- | --------- |
| 1 | Sine | Fundamental only |
| 2 | Sawtooth | All harmonics (1/n) |
| 3 | Square | Odd harmonics (1/n) |
| 4 | Triangle | Odd harmonics (1/n²) |
| 5 | Pulse | 25% duty cycle — odd + even harmonics |
| 6 | Organ | Harmonics 1–4 with ½, ¼, ⅛ weights |
| 7 | Additive | 3 odd harmonics: sin + sin(3f)/3 + sin(5f)/5 |
| 8 | Custom | User-drawn one-cycle waveform (browser only) |

## Terminal

### Run

```bash
cargo run --release
```

### Controls

| Keys | Action |
| ------- | ------- |
| `A W S E D F T G Y H U J K` | Play notes C4 → C5 (QWERTY piano layout) |
| `1` `2` `3` `4` | Switch waveform |
| `Q` / `Esc` | Quit |

White keys on the home row, black keys on the top row.

## Browser (WASM)

### Requirements

```bash
rustup update stable
rustup target add wasm32-unknown-unknown
cargo install wasm-pack
```

### Build

```bash
wasm-pack build --target web --out-dir web/pkg
```

### Serve

```bash
cd web && python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

### GUI panels

| Panel | Description |
| ------- | ----------- |
| **Oscilloscope** | Live waveform preview — grey when idle, blue when playing |
| **Waveform** | 8 shapes (Sine, Saw, Square, Triangle, Pulse, Organ, Additive, Custom); selecting Custom shows a draw canvas — drag to sculpt one cycle |
| **ADSR Envelope** | Interactive canvas — drag the green handle (X = attack time), yellow handle (X = decay time, Y = sustain level), red handle (X = release time) |
| **Filter** | Biquad filter with a cycling type selector (LP → HP → BP → LP), two rotary knobs (Cutoff log 20 Hz–20 kHz, Resonance 0.1–20), and a frequency-response display |
| **Keyboard** | 5-octave piano (C2–C7); click/touch keys or use `A W S E D F T G Y H U J K` for C4–C5; supports multi-touch and up to 8 simultaneous notes |
| **Frequency** | Logarithmic slider (20–4000 Hz) — controls oscillator pitch independently of the piano; shows Hz and nearest note name |

## Project structure

```text
src/
  main.rs          # Terminal binary (cpal + crossterm)
  lib.rs           # Library root — shared by WASM build
  wavetable.rs     # Table generation (8 waveforms: sine, saw, square, triangle, pulse, organ, additive + custom slot)
  oscillator.rs    # Phase accumulator + linear interpolation; holds all 8 tables
  adsr.rs          # ADSR envelope with live parameter setters
  filter.rs        # Biquad filter (LP / HP / BP, Audio EQ Cookbook)
  keys.rs          # QWERTY → MIDI mapping (terminal only)
  wasm_synth.rs    # wasm-bindgen Synth wrapper — 8-voice polyphony with voice stealing (WASM only)
web/
  index.html       # Self-contained browser GUI
  pkg/             # Generated by wasm-pack (not committed)
```
